# Email Spam Detection

This project detects whether an email is spam or not using Machine Learning in Python.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Naive Bayes Algorithm

## Features

- Detects spam emails
- Simple machine learning model
- Easy to understand
- Beginner friendly project
